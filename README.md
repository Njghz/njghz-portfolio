# Njighz — портфолио веб-разработчика

Личный сайт-портфолио на HTML, CSS и JavaScript. Тёмная тема, адаптивная вёрстка, анимации и страницы учебных проектов.

## Структура

```text
.
├── .github/
│   └── workflows/
│       └── pages.yml
├── css/
│   └── styles.css
├── js/
│   └── main.js
├── projects/
│   ├── discord-bot.html
│   ├── portfolio.html
│   └── python-app.html
├── index.html
└── README.md
```

Все файлы сайта находятся в корне репозитория. Папка `my-first-site` при загрузке на GitHub становится корнем сайта, поэтому вложенная папка не нужна.

## Локальный просмотр

Можно открыть `index.html` напрямую в браузере. Для проверки локального сервера, если установлен Python:

```bash
python -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создай на GitHub **публичный** репозиторий. Публикация через GitHub Pages доступна бесплатно для публичных репозиториев.
2. Загрузи в него всё содержимое папки `my-first-site`, включая скрытую папку `.github`.
3. Убедись, что `index.html` находится непосредственно в корне репозитория.
4. В репозитории открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Source: GitHub Actions**.
6. Отправь изменения в ветку `main`. Workflow автоматически опубликует сайт.

Сайт будет доступен по адресу:

```text
https://<имя-пользователя>.github.io/<имя-репозитория>/
```

Если репозиторий называется `<имя-пользователя>.github.io`, адрес будет таким:

```text
https://<имя-пользователя>.github.io/
```

## Обновление сайта

После изменения файлов загрузи их в ветку `main`. GitHub Actions автоматически пересоберёт и опубликует новую версию сайта.
