Python-приложение

Трекер задач

Консольное приложение для списка дел. Можно добавлять задачу, отмечать выполнение, фильтровать по статусу и сохранять данные между запусками.

Как устроено

  • Меню в терминале: добавить, показать, закрыть задачу
  • Хранение в JSON-файле, без базы данных
  • Проверки ввода, чтобы программа не падала на пустой строке

Написано на чистом Python. Ссылку на код добавлю вместе с остальными контактами.
